# خلاصهٔ قابل بازیابی پروژه‌ها و تصمیم‌های کاربر

این سند خلاصه است، نه رونوشت کامل تاریخچه. جزئیات ذکرنشده را حدس نزنید.

## TriGate

- درخواست فعلی بازنویسی کامل از صفر؛ نه بازیابی سورس برنامهٔ قدیمی. اول APK اندروید گوشی و بعد EXE ویندوز ۱۰ به بالا x64؛ سورس و خروجی‌ها در Google Drive. رابط حرفه‌ای و روان، فارسی و انگلیسی، سبک iOS.
- مشکلات درخواستی: Fenix و زنجیرهٔ پروکسی SOCKS4/5 و HTTP(S)، Moat، ادغام واقعی Psiphon/Lantern، split برحسب برنامه/سایت. درخواست بدون باگ هدف است نه نتیجهٔ تأییدشده.
- پروژهٔ جدید دارای رابط اندروید اولیه و میزبان محلی Psiphon است. تنظیمات اولیه و server entries از MLMVPN وارد شده؛ با بستن صفحه متوقف می‌شود. Windows صرفاً میزبان کنسولی توسعه‌ای ConsoleClient است. هیچ‌کدام VPN کامل نیست.
- زنجیرهٔ مستقل قبلی TCP برای SOCKS4/4a، SOCKS5 و HTTP(S) CONNECT، بدون fallback مستقیم، صرفاً کتابخانهٔ مستقل است، نه اتصال اثبات‌شده به Fenix/UI؛ UDP ندارد. بستهٔ آن در `ARTIFACTS-FA.md` است.
- نسخهٔ preview قبلی از نظر split سایت و جلوگیری از نشت تضمین‌شده نبود. Windows per-app، lifecycle و اتصال Fenix به زنجیره تأیید نشدند. اتصال واقعی، سرعت، عدم نشت یا امنیت هیچ‌یک از خروجی‌های ناقص تضمین نشده است.
- Psiphon واقعی در MLMVPN بررسی شد و badvpn/tun2socks در سورس وجود دارد؛ بعضی باینری‌های native تنها Git LFS pointer هستند. README MLMVPN از Lantern و Fenix می‌گوید اما جست‌وجوی کد در commit بررسی‌شده پیاده‌سازی واضحی برای آن‌ها پیدا نکرد؛ فرض وجود آن‌ها اشتباه است.
- APK قدیمی، EXE و UI کامل سورس قابل بازسازی فراهم نکردند. JADX هشت متد مهم را نتوانست کامل decompile کند؛ سورس اصلی Go/Java نسخهٔ قدیمی یافت نشد. کلید اصلی `trigate-release.p12` نیز پیدا نشد. امضا و package نسخهٔ dev جدید با نسخهٔ اصلی متفاوت است؛ آپدیت مستقیم فرض نشود.
- iOS در کار قبلی مدنظر بود: نصب بدون کابل از طریق IPA installer؛ همهٔ ویژگی‌های Android خواسته شده بود. Linux بدون Xcode/پروژه iOS نمی‌تواند APK را به IPA تبدیل کند؛ TestFlight به build و حساب Developer و VPN به API و entitlement مربوط نیاز دارد. درخواست فعلی Android و Windows است.

## سایر پروژه‌ها در گفت‌وگو

- **ProtonGate:** اصلاح افزایشی برنامهٔ موجود، بدون بازنویسی، ورود از صفحهٔ رسمی Proton و بازگشت به برنامه. مشکل اتصال همهٔ سرورها مربوط به ProtonGate بود، نه TriGate. دربارهٔ نتیجهٔ عملی آن شواهد کافی در این خلاصه نیست.
- **Arena AI:** طبق آخرین تصمیم کاربر فقط نوار تب قابل جابه‌جایی، ذخیرهٔ رمز و بوکمارک، Tor و Fenix به آخرین نسخهٔ موجود افزوده و APK/EXE تولید شود؛ دامنهٔ گستردهٔ قبلی کنار گذاشته شده. اتصال MTProto در teleproto مستقیم باشد. سورس کامل یا تکمیل‌شدن این امکانات از این خلاصه ثابت نیست.
- **IranRoute:** استفاده از فهرست‌های پروکسی ایرانی SOCKS4/5 و HTTP(S) از منابع مختلف مانند منابع TriGate انتخاب شد. IP ایرانی تضمین تعرفهٔ داخلی نیست؛ پراکسی عمومی ریسک شنود دارد.
- در کار میزبان افزونه، خود برنامه نباید مرورگر باشد و باید host / VpnService / bridge باشد.

## احتیاط‌های فنی و تحویل

- Moat و پل دستی به‌تنهایی به معنی رفع backend نیستند. CDN/451 و رفتار سرویس را مجزا بررسی کنید.
- APK و EXE ساخته‌شده با سورس ناقص متفاوت‌اند؛ اصالت signer، نسخه، معماری و منشأ هر فایل را جداگانه بررسی کنید.
- از public کردن کلیدها، رمزها و داده‌های خصوصی خودداری کنید. فایل‌های عمومی قبلی را بدون بررسی به‌عنوان نسخهٔ نهایی معرفی نکنید.
- نسخهٔ جدید APK ۰.۲ فقط با aapt2/ECJ/D8/apksigner کامپایل و از نظر امضا بررسی شد، نه Gradle کامل و نه اجرا/اتصال. خروجی Windows WIP در مراحل پیشین cross-build شد، اما روی Windows اجرا نشد.
