# TriGate جدید — شروع پروژه از صفر (نسخهٔ توسعه‌ای ناقص)

این یک پروژهٔ جدید است، نه سورس بازسازی‌شدهٔ نسخهٔ قبلی. در حال حاضر **برنامهٔ نهایی یا VPN آمادهٔ استفاده نیست**. APK نسخهٔ توسعه‌ای ۰.۲ صرفاً پروکسی محلی است؛ APK یا EXE نهایی تولید نشده است. جزئیات ساخت و محدودیت‌ها در `ANDROID-PROXY-DEV.md` آمده است.

## آنچه در کد فعلی وجود دارد

- `android/`: رابط سادهٔ دوزبانهٔ اندروید و میزبان جدید برای کتابخانهٔ رسمی Psiphon، با واردکردن تنظیمات و فهرست سرور و کنترل start/stop. این نسخه فقط یک پروکسی SOCKS محلی در حالت آزمایشی راه می‌اندازد. VPN سراسری، VpnService و عبور خودکار ترافیک برنامه‌ها ندارد؛ پروکسی برای سایر برنامه‌های محلی قابل دسترسی است. با بسته‌شدن صفحه متوقف می‌شود. تنظیمات اولیه و فهرست سرور از MLMVPN در بسته قرار گرفته‌اند و ورود فایل جایگزین نیز ممکن است؛ به‌روز یا قابل‌اتصال بودن آن‌ها تأیید نشده است. اتصال واقعی روی دستگاه بررسی نشده است.
- `internal/psiphon/` و `cmd/trigate-psiphon/`: کد جدید Windows/desktop برای اجرای مستقل ConsoleClient رسمی Psiphon با ورودی پیکربندی، توقف فرایند و خواندن وضعیت از اعلان‌های واقعی هسته. برنامهٔ کنسولی توسعه‌ای است، نه رابط ویندوز، نه VPN سیستم، و به فایل اجرایی رسمی ConsoleClient و پیکربندی معتبر نیاز دارد. صرف گوش‌دادن پورت به معنی اتصال نیست؛ وضعیت متصل فقط پس از اعلان تونل و پورت SOCKS ارسال می‌شود. از طریق `-client`, `-config`, `-data`, `-servers` پیکربندی می‌شود. `-servers` اختیاری است. این فایل‌ها خصوصی بمانند.

## موارد مهمی که هنوز وجود ندارند

Lantern، Tor، Fenix، DNS Shield، OmniGate، TeleProto و eFlux پیاده‌سازی نشده‌اند. مسیریابی VPN اندروید و ویندوز، رابط کامل ویندوز، split tunneling، chaining، حفاظت از DNS و ساخت و امضای نهایی هم کامل نشده‌اند. نباید به این نسخه برای امنیت، جلوگیری از نشت یا دور زدن فیلترینگ اعتماد کرد. بنابراین قابلیت‌های درخواست‌شده هنوز کامل نیستند.

## ساخت برای توسعه‌دهنده

اندروید: JDK 17، Android SDK با API 34 و Gradle 8.4 لازم است؛ از مسیر `android/` دستور `gradle :app:assembleDebug` را اجرا کنید. وابستگی دودویی `android/app/libs/psiphontunnel-2.0.39.aar` در بستهٔ Drive موجود است. این APK توسعه‌ای، جایگزین برنامهٔ نهایی نیست و با کلید debug امضا می‌شود.

ویندوز: Go 1.22 به بالا لازم است؛ در shell یونیکس از ریشهٔ پروژه اجرا کنید:

```
GOOS=windows GOARCH=amd64 go build -o trigate-psiphon-dev-win64.exe ./cmd/trigate-psiphon
```

در PowerShell به‌جای پیشوند، از `$env:GOOS='windows'; $env:GOARCH='amd64'` استفاده کنید. این فایل برای کار به ConsoleClient رسمی و تنظیمات معتبر نیاز دارد؛ آن را به‌عنوان برنامهٔ کامل معرفی نکنید.

## منشأ و مجوز

کد جدید تحت GPL-3.0-or-later است؛ فایل `LICENSE` ضمیمه شده. Psiphon Tunnel Core کتابخانهٔ ثالث GPL-3.0-or-later است: https://github.com/Psiphon-Labs/psiphon-tunnel-core . کتابخانهٔ موجود `psiphontunnel-2.0.39.aar` همان AAR موجود MLMVPN است؛ build info باینری arm64، revision `cd31fecf7b` را نشان می‌دهد که با tag رسمی v2.0.39 تطبیق دارد. سورس همان revision در `third_party/psiphon-tunnel-core-v2.0.39.tar.gz` داخل بسته قرار داده شده است؛ مجوزها و وابستگی‌های بالادستی داخل آن را هنگام توزیع بررسی کنید. فایل‌های پیکربندی، اعتبارنامه و کلید امضا در بسته نیستند.

## بررسی انجام‌شده

کد Go در مرحلهٔ پیشین با `go build` و `go vet` بررسی و برای Windows amd64 cross-build شد. کد فعلی اندروید با API 34 و AAR سایفون MLMVPN کامپایل و با D8 و aapt2 بسته‌بندی شد و امضای APK با apksigner بررسی شد. ساخت کامل Gradle، اجرای واقعی روی دستگاه، اجرای ویندوز و اتصال شبکه انجام نشده‌اند.
